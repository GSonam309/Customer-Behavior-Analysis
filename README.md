# Customer-Behavior-Analysis
Data analytics project showcasing customer behavior analysis using- Python and its libraries, SQL, and Power BI.
# Some of the steps I followed:
- Step 1. Collected the customer shopping behavior dataset (.csv).
- Step 2. Imported the dataset into Jupyter Notebook using Python.
- Step 3. Cleaned and preprocessed the data using Pandas.
- Step 4. Performed Exploratory Data Analysis (EDA) to identify customer purchasing patterns and trends.
- Step 5. Exported the cleaned dataset from Jupyter Notebook.
- Step 6. Imported the cleaned dataset into SQL Server (SSMS).
- Step 7. Wrote SQL queries to perform business analysis and generate insights.
- Step 8. Connected SQL Server (SSMS) to Power BI.
- Step 9. Imported the analyzed data into Power BI.
- Step 10. Created DAX measures and KPIs.
- Step 11. Designed an interactive dashboard using charts, cards, slicers, and filters.
- Step 12. Derived business insights and recommendations from the dashboard.
